# Love-Percentage-Calculator
❤️ Love Percentage Calculator

A simple and attractive Love Percentage Calculator built using HTML, CSS, and JavaScript.

Enter the names of a boy and a girl to calculate their love percentage and display a romantic couple message. 💕

✨ Features

- 👦 Boy name input
- 👧 Girl name input
- ❤️ Love percentage calculation
- 📊 Animated progress bar
- 💕 Floating heart animation
- 💖 Romantic result messages
- 📱 Mobile responsive design
- 🌐 Easy to deploy on GitHub Pages
- ⚡ No external libraries required

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

📂 Project Structure

Love-Percentage-Calculator/
│
└── index.html

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in any web browser.
4. Enter the Boy Name and Girl Name.
5. Click Calculate Love %.
6. See the love percentage and result. ❤️
