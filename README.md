# Love-Percentage-Calculator
❤️ Love Percentage Calculator

A simple and interactive Love Percentage Calculator built using HTML, CSS, and JavaScript.

The project calculates love percentage in both directions:

- 👦 Boy → Girl
- 👧 Girl → Boy
- 💕 Check Both

✨ Features

- ❤️ Love percentage calculation
- 👦 Boy → Girl option
- 👧 Girl → Boy option
- 💕 Check Both option
- 📱 Mobile-friendly responsive design
- 🎨 Attractive pink love-themed UI
- 💖 Love result messages
- ⚡ Fast and easy to use
- 🌐 Works directly in a web browser

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in any web browser.
4. Enter the Boy Name and Girl Name.
5. Select:
   - Boy → Girl
   - Girl → Boy
   - Check Both
6. Your love percentage will be displayed.
